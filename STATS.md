# Connecting GitHub Activity to your account

The streak, languages, and contribution graph cards are generated by
`.github/workflows/update-readme-stats.yml` using GitHub's REST + GraphQL APIs
for user `clarenceportugal`.

## Why numbers can look "not connected"

By default the workflow uses the Actions bot token (`GITHUB_TOKEN`). That only
sees **public** contribution data. To match your profile more closely
(including private contributions you chose to show on your profile), add a
Personal Access Token.

## One-time setup (recommended)

1. Open GitHub → **Settings** → **Developer settings** → **Personal access tokens**
   - Classic: create a token with scope `read:user`
   - Or fine-grained: Resource owner = you, Repository access = Public
     repositories (or All), Account permissions → **Profile** = Read
2. Copy the token.
3. Open https://github.com/clarenceportugal/clarenceportugal/settings/secrets/actions
4. **New repository secret**
   - Name: `PROFILE_STATS_TOKEN`
   - Value: paste your token
5. Open https://github.com/clarenceportugal/clarenceportugal/actions
6. Select **Update README Stats** → **Run workflow** → **Run workflow**

Optional: Profile → **Contribution settings** → enable
**Include private contributions on my profile** if you want private work counted.

After the run finishes, hard-refresh your profile page (Ctrl+F5). GitHub image
cache (Camo) can take a few minutes to show the new SVGs.
